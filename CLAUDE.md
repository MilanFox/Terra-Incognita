## Agent skills

### Issue tracker

Issues, maps and specs live in Chartroom at http://localhost:3000, accessed via the `chartroom` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), managed by Chartroom. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
